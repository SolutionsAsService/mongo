About

The only claims here are ones the build checks.

How the numbers get here

python3 _src/build.py runs each query in _src/queries.json with _src/evaluator.py on _src/data.json, then runs the equivalent SQL in SQLite on the same data and stops if the answers differ. Eleven of eleven agreed at build time.

What is not covered

The evaluator is this site's own, about 150 lines, and covers only the operators shown. It is not mongod: indexes, ObjectId generation, type ordering, transactions and every other operator are outside it. To see a result from a real server, run the shown query in mongosh. Data is invented; nobody in it is real.
