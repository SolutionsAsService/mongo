countDocuments and the aggregation pipeline: $sum, $avg and $group.

An aggregation pipeline is a list of stages; each feeds the next. Every query here reads the original, unchanged collections.

countDocuments

7 documents counted

Count the documents in a collection.

db.users.countDocuments({})

Result

7

In SQL

SELECT COUNT(*) FROM users;

The SQL gives the same answer: the build runs both on the same data and stops if they differ.

Reading it

  • countDocuments({}) counts every document; pass a filter to count only some.

$sum

550.75 total sales

Add up one field across all documents with an aggregation pipeline.

db.orders.aggregate([
  { $group: { _id: null, total_sales: { $sum: "$order_amount" } } }
])

Result: 1 document

result documents

  1. { _id: null, total_sales: 550.75 }

In SQL

SELECT SUM(order_amount) AS total_sales FROM orders;

The SQL gives the same answer: the build runs both on the same data and stops if they differ.

Reading it

  • $group with _id: null puts every document in one group.
  • $sum: "$order_amount" adds the field named after the dollar sign.

$avg

25.8571 average age

Average one field across all documents.

db.users.aggregate([
  { $group: { _id: null, average_age: { $avg: "$age" } } }
])

Result: 1 document

result documents

  1. { _id: null, average_age: 25.857142857142858 }

In SQL

SELECT AVG(age) AS average_age FROM users;

The SQL gives the same answer: the build runs both on the same data and stops if they differ.

Reading it

  • $avg ignores documents where the field is missing or not a number.

$group

5 groups

One output document per distinct value of a field.

db.users.aggregate([
  { $group: { _id: "$age", count: { $sum: 1 } } }
])

Result: 5 documents

result documents

  1. { _id: 25, count: 2 }
  2. { _id: 42, count: 1 }
  3. { _id: 19, count: 2 }
  4. { _id: 17, count: 1 }
  5. { _id: 34, count: 1 }

In SQL

SELECT age, COUNT(*) AS count FROM users GROUP BY age;

The SQL gives the same answer: the build runs both on the same data and stops if they differ.

Reading it

  • _id: "$age" is the group key: one output document per age.
  • $sum: 1 counts the documents in each group.
